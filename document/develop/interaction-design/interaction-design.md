# 交互设计

查看器（DocGraphViewer）的完整交互逻辑，全部以流程图展示。

核心原则：**文档文件是画布状态的唯一事实来源**。画布上的一切修改（拖框、增删连线、编辑正文）都走同一个闭环——保存 API 写回源文件，目录监听捕获变更，热更新回推客户端，画布随之重建。图编辑模式下的修改先**暂存为本地覆盖**（画布即时反映），「💾 保存」统一写回，「↩ 放弃更改」整批丢弃。

## 一、视图状态机

查看器有三个稳定状态，地址栏 hash 始终同步当前文档路径：

```prodoc-flow
graph LR
  Canvas[图画布视图] -->|单击框| Doc[正文视图]
  Canvas -->|🛠 编辑图| GraphEdit[图编辑模式]
  GraphEdit -->|✓ 完成 或 ↩ 放弃更改| Canvas
  GraphEdit -->|💾 保存| Persist[写回源文件]
  Persist -->|热更新回推| GraphEdit
  Doc -->|🗺 返回图| Canvas
  Doc -->|✏️ 编辑| Editing[编辑状态]
  Editing -->|👁 预览| Doc
  Editing -->|💾 保存| Persist
GraphEdit @ 227, 135
```

图编辑模式是画布视图的子模式：其中有暂存修改时只能经「💾 保存」（留在编辑模式继续）或「↩ 放弃更改」（丢弃并退出）离开，无暂存时「✓ 完成」退出——未保存的修改不会被悄悄带走。正文编辑态同理：有未保存修改时点「🗺 返回图」会先弹确认，确认后才丢弃修改。

## 二、图编辑模式（编辑状态）

浏览是默认状态；「🛠 编辑图」开启编辑模式后，画布才开放框、连线与分组区域的编辑能力（此时单击框不再打开文档，避免拖拽误触；分块面板与框上的编辑入口也一并隐藏）。**修改不即时写文件**——所有编辑先暂存为本地覆盖，画布即时反映暂存结果。编辑状态下的全部操作及其汇入的暂存闭环：

```prodoc-flow
graph TB
  Toggle[点 🛠 编辑图] --> Mode[进入图编辑模式：底部出现工具栏]
  Mode --> Drag[🖱 拖拽框调整位置]
  Mode --> Handle[🖱/🔗 连接点或连线工具：源框拖到目标框]
  Mode --> NodeNew[📄 节点工具：点空白创建新文档框]
  Mode --> Pick[🖱 单击连线选中]
  Mode --> GroupMove[🖱 拖组名标签：整组移动]
  Mode --> GroupResize[🖱 拖组区域右下角手柄：调整长宽]
  Pick --> SideDrag[拖动端点手柄到目标边，实时预览]
  Pick --> LabelEd[双击：中点输入框编辑标签]
  Pick --> Del[中点 ✕ 或 Delete 删除]
  Drag --> Stage[暂存为本地覆盖，画布即时反映]
  Handle --> Stage
  NodeNew --> Stage
  SideDrag --> Stage
  LabelEd --> Stage
  Del --> Stage
  GroupMove --> Stage
  GroupResize --> Stage
  Stage --> Save[💾 保存：逐文件批量写回，热更新回推]
  Stage --> Abort[↩ 放弃更改：整批丢弃，退出编辑模式]
```

保存以客户端已知的磁盘内容为基准做冲突检测：全部写盘成功后暂存即清空、按钮即复位（不依赖热更新到达，避免推送丢失时按钮卡死），成功文件的本地基准即时同步，服务端热更新随后推送最新文件重建画布；写盘失败（409 冲突或请求出错）的文件**保留暂存**并弹窗提示，用户可刷新页面同步后重试或「↩ 放弃更改」丢弃。

### 2.1 交互清单

编辑状态下的全部交互逻辑，按操作对象分组列举：

**进出编辑状态**

- 头部「🛠 编辑图」进入；有暂存修改时退出被阻止——只能「💾 保存」（留在编辑状态继续）或「↩ 放弃更改」（丢弃并退出）；无暂存时「✓ 完成」退出
- 进入编辑状态后：单击 / Enter / Space 不再打开文档（避免拖拽误触）；悬停分块面板与框上 ✏️ 编辑入口隐藏；框呈现可拖拽姿态（抓手光标 + 主色描边环）；连线变为可点选；组名标签与区域右下角手柄出现；画布底部出现工具栏

**工具栏**

- 编辑状态底部居中悬浮（位于缩放控件上方），三个工具：🖱 选择（默认）/ 🔗 连线 / 📄 节点；当前工具高亮；Esc 分级生效——有选中连线时先取消选中，否则切回选择工具（点 🖱 直接切回）；退出编辑状态时复位为选择
- **🔗 连线工具**：光标变为十字；从任意框按下即拖出草稿曲线（整个框都是起点），落到目标框松手创建；激活期间拖拽手势用于连线，框不可拖移
- **📄 节点工具**：点画布空白处，在该位置创建新文档框（`untitled-N.md` 新文件暂存草稿，详见 §2.5）

**框**

- **拖拽移动**：左键按下后位移达到 3px 才定性为拖拽（否则视为单击）；位移按当前缩放折算（缩放在按下时缓存，避免逐帧强制布局）；位置更新经 rAF 收敛到每帧一次；拖拽期间禁用框的过渡动画
- **吸附对齐**：候选位置与其他框的六条特征线（左/中/右、上/中/下）比较，阈值按缩放折算（屏幕约 8px，限幅 4–12 舞台 px），取最近线吸附；吸附后显示全部命中的对齐参考线（共线者合并跨度）
- **边界钳制**：坐标钳制不为负——框（含整组移动）不可被拖出画布左上边界，避免负坐标写回后框丢失在可视区外
- **边缘自动平移**：拖拽中指针贴近视口边缘（40px 内）时画布按距离梯度自动滚动，长距离移动无需松手换拖
- **方向键微调**：选择工具下聚焦框后按方向键移动 1px（Shift 为 10px），实时暂存；800ms 内的连续微调合并为一个撤销点
- **松手**：坐标取整后经 `writeFramePosition` 暂存；松手瞬间的 click 事件被抑制，不会误打开文档

**连线**

- **创建**：从框四边中点的连接点（选择工具下，悬停框时显现；从哪条边拖出即固定该边为源边）拖出，或连线工具下从任意框按下拖出草稿曲线（按下点方位取最近边为源边；复用边缘中点几何，起点即带法线切向），松手命中目标框即暂存「源文档 `link` 追加目标条目」——落点方位取目标框最近边，条目含连接边段（如 `guide | b>l`）；自连与重复连线自动忽略，落空丢弃草稿；创建成功播放一次描边入场动画
- **选中**：单击连线（14px 透明命中路径，无需精确命中 2px 可见曲线）；选中后连线主色加粗、端点出手柄、中点法线偏移处出 ✕（不压住标签文字）；点画布空白处或按 Esc 取消选中
- **调整连接边**：拖动端点手柄，按光标相对框心的方位（宽高归一化后的主导轴）实时预览目标边；松手暂存条目第三段更新（只动一端时另一端记 `_` 保持自动）；与现状一致时不产生暂存
- **编辑标签**：双击连线，中点弹出内联输入框（预填当前标签，自动聚焦全选）；Enter 或失焦确认、Esc 取消；清空即移除标签段；未改动不产生暂存；输入期间 Delete / Backspace 作用于文本（不触发删除连线）
- **删除**：点 ✕ 或按 Delete / Backspace（仅画布视图 + 编辑状态 + 有选中连线且不在标签输入中时响应），暂存从源文档 `link` 移除匹配条目，其余条目（含标签、连接边原文）无损保留

**分组区域**

- **整组移动**：拖动组名标签，成员坐标整体平移（逐框位置覆盖实时预览）；区域六条特征线与组外框、其他组区域吸附对齐并显示参考线；松手逐成员暂存，显式几何组的几何持有者 `group` 条目同步平移暂存
- **调整长宽**：拖动区域右下角手柄；右/下边缘参与吸附；下限钳制为成员包围盒 + 内边距（成员不外溢）；松手后区域转为显式几何（`group: "名称 @ x, y, w, h"`），暂存到几何持有者文档

**暂存与退出**

- **暂存**：所有修改先存为本地覆盖，画布即时重建反映暂存结果；改回与磁盘内容一致的修改自动撤销该文件的暂存，不计入待保存
- **撤销/重做**：Ctrl/Cmd+Z 撤销、Ctrl+Shift+Z 或 Ctrl+Y 重做（头部 ↶/↷ 按钮同效）；以操作前快照为单位（含暂存内容、删除标记与位置覆盖），无实际改动的操作不产生撤销点；保存成功、放弃或退出编辑时清空
- **💾 保存**：全部暂存（内容修改 + 删除标记）逐文件携带基准内容提交保存/删除 API（磁盘已被外部修改则 409 拒绝）；全部成功后即清空暂存与撤销栈、复位按钮并 toast 提示，成功文件的本地基准即时同步（后续保存不等热更新推送）；**失败的文件保留暂存**并 toast 提示（可刷新后重试或放弃）；服务端热更新随后推送最新文件，画布原地重建
- **↩ 放弃更改**：丢弃全部暂存与被暂存框的位置覆盖、删除标记，清除连线选中，退出编辑状态
- **新建文件草稿**：节点工具创建的 `untitled-N.md` 暂存带新建标记，热更新修剪时「磁盘上不存在」不视为删除信号（写盘前本就不存在）；仅在写盘成功或主动放弃时移除
- **删除节点**：悬停框点右上角 ✕——磁盘文件弹确认后标记删除（危险色虚线 + 标题删除线，再点 ↩ 撤销标记），新建草稿直接消失；保存时经删除 API 删文件（409 冲突保留标记）
- **暂存持久化**：暂存内容、新建草稿与删除标记随操作写入 localStorage（以文档服务源为键）；刷新/重开后按磁盘基准校验恢复——内容已一致或基准已偏离的条目丢弃，其余恢复并自动进入编辑模式提示
- 悬停高亮链路在编辑状态下仍然可用（拖拽进行中除外），便于编辑时辨认上下游关系

### 2.2 工具栏与工具切换

进入编辑状态后，画布底部居中悬浮**工具栏**，承载三个工具；当前工具高亮，Esc（有选中连线时先取消选中）或点 🖱 随时回到选择，退出编辑状态时复位：

```prodoc-flow
graph LR
  Select[🖱 选择（默认）] -->|点 🔗| Link[🔗 连线工具]
  Select -->|点 📄| Node[📄 节点工具]
  Link -->|Esc 或点 🖱| Select
  Node -->|Esc 或点 🖱| Select
```

- **🖱 选择**：默认工具，承载既有全部行为——拖框、点选/双击连线、组操作
- **🔗 连线**：光标变为十字；从**任意框**按下即拖出草稿曲线（整个框都是起点，按下点方位取最近边为源边），落到目标框松手创建；此工具下拖拽手势用于连线，框不可拖移
- **📄 节点**：点画布空白处在该位置**创建新文档框**（新建文件草稿，见 §2.5）

### 2.3 单击与拖拽的判定

框上的指针按下不立即定性，按位移分流——单击打开文档，拖拽修改坐标（拖拽修改坐标需编辑状态且处于选择工具；连线工具下同一手势用于创建连线）：

```prodoc-flow
graph TB
  Down[指针按下框] --> Judge{位移达到 3px}
  Judge -->|否| Open[单击：打开文档正文]
  Judge -->|是| Drag[拖拽：按缩放折算位移，实时更新覆盖坐标]
  Drag --> Drop[松手]
  Drop --> Stage[暂存坐标修改（含 writeFramePosition 后的完整内容）]
  Stage --> Save[💾 保存：POST 保存 API]
  Save --> Loop[热更新回推，图重建固定新坐标]
```

拖拽中连线实时跟随（几何基于覆盖坐标计算）；松手瞬间的 click 事件被抑制，不会误打开文档；松手后修改进入暂存，「💾 保存」才写回文件，「↩ 放弃更改」连同位置覆盖一并还原。拖动接近其他框的**左/中/右、上/中/下**特征线时自动吸附并显示对齐参考线；坐标钳制不为负（不可拖出画布左上边界）；指针贴近视口边缘时画布自动平移。跟手性的三个要点：位置更新收敛到**每帧一次**（rAF 节流）、拖拽期间**禁用框的过渡动画**（过渡只为分层重排服务）、缩放在按下时缓存（避免逐帧强制布局）。

### 2.4 创建连线

两个入口殊途同归：选择工具下从框四边中点的**连接点**拖出（从哪条边拖出即固定该边为源边），或**连线工具**下从任意框按下拖出（按下点方位取最近边为源边）：

```prodoc-flow
graph TB
  Start[连接点按下，或连线工具下从源框按下] --> Draft[草稿曲线跟随光标]
  Draft --> Up[松手]
  Up --> Hit{命中目标框}
  Hit -->|否| Discard[丢弃草稿]
  Hit -->|是| Valid{非自连且不重复}
  Valid -->|否| Discard
  Valid -->|是| Append[暂存：源文档 link 追加目标条目（含连接边段）]
  Append --> Save[💾 保存，热更新回推]
```

连接点仅在图编辑模式下出现，悬停框时四边中点各显现一个。草稿曲线复用边缘中点几何：起点就带法线切向，落点处即最终形态——落点所在方位取目标框最近边作为目标边，暂存条目形如 `guide | b>l`（无标签、仅连接边）。创建成功后新连线播放一次描边入场动画（dashoffset 从路径全长归零）。

### 2.5 创建节点

📄 节点工具下点画布空白处，在该位置创建一个新文档框（新文件草稿）：

```prodoc-flow
graph TB
  Click[节点工具下点画布空白] --> Create[生成 untitled-N.md 草稿：参数区含 title 与 x/y，正文为同名 H1]
  Create --> Stage[暂存：画布即时出现新框，点击点居中取整]
  Stage --> Save[💾 保存：保存 API 创建文件]
  Stage --> Abort[↩ 放弃更改：草稿丢弃，新框消失]
```

- **编号**：`untitled-N.md` 取当前未占用的最小 N（磁盘文件与暂存中的新文件一并计算）；标题「未命名文档 N」；`id` 缺省为 `untitled-N`
- **新文件草稿的保护**：热更新回推修剪暂存时，「磁盘上不存在」对新建草稿是正常状态而非删除信号——带新建标记的草稿仅在写盘成功（内容一致回推）或主动放弃时才清除
- **保存前不可打开正文**：正文视图基于磁盘内容，新框保存落盘后才可打开编辑（改标题/正文用内置编辑器）
- 新框与其余框一样参与连线、整组移动与吸附对齐

### 2.6 选中、标签与删除连线

```prodoc-flow
graph TB
  Click[单击连线] --> Selected[选中：主色加粗，端点出手柄，中点出 ✕]
  Selected --> How{后续操作}
  How -->|拖动端点手柄| SidePrev[按光标方位实时预览目标边]
  SidePrev -->|松手| Rewrite[暂存：条目第三段更新]
  How -->|双击连线| LabelIn[中点弹出输入框，预填当前标签]
  LabelIn -->|Enter 或失焦| LabelSave[暂存：条目标签段更新，清空即移除]
  LabelIn -->|Esc| Keep[取消，不改动]
  How -->|点 ✕ 或 Delete| Remove[暂存：从源文档 link 移除匹配条目]
  Rewrite --> Save[💾 保存，热更新回推]
  LabelSave --> Save
  Remove --> Save
```

连线有一条 14px 宽的透明命中路径，让点选不需要精确命中 2px 的可见曲线；点选与双击仅在图编辑模式下可用。标签编辑经 `buildLinkEntry` 重建条目——保留引用原文与连接边段，标签为空时整条标签段移除；输入期间 Delete / Backspace 作用于文本，不触发删除连线。

### 2.7 分组区域：整组移动与尺寸调整

分组区域的两个操作同样走暂存闭环，拖拽中与框拖拽共用同一套**吸附对齐**（阈值按缩放折算为屏幕约 8px）：

```prodoc-flow
graph TB
  Move[拖动组名标签] --> SnapM[区域六条特征线与组外框、其他区域吸附对齐]
  SnapM --> DropM[松手：逐成员暂存新坐标]
  DropM --> HolderM{显式几何组}
  HolderM -->|是| ShiftM[几何持有者的 group 条目同步平移暂存]
  HolderM -->|否| Stage[暂存为本地覆盖]
  ShiftM --> Stage
  Resize[拖动区域右下角手柄] --> SnapR[右与下边缘吸附对齐]
  SnapR --> Clamp[下限钳制：成员包围盒加内边距，成员不外溢]
  Clamp --> DropR[松手：区域转为显式几何，暂存几何持有者的 group 条目]
  DropR --> Stage
```

- **整组移动**：成员坐标整体平移（逐框位置覆盖实时预览），松手后逐成员暂存（`writeFramePosition`）；显式几何组的几何持有者 `group` 条目同步平移暂存（`writeFrameGroup`），区域不脱离成员
- **调整长宽**：松手后区域转为显式几何（`group: "名称 @ x, y, w, h"`），暂存到几何持有者文档；下限 = 成员包围盒 + 内边距，保证成员不溢出区域
- 两者都在「💾 保存」时逐文件写回，「↩ 放弃更改」连同暂存与位置覆盖一并丢弃

## 三、编辑与热更新闭环

内置编辑与外部编辑器殊途同归，都汇入目录监听的回推回路：

```prodoc-flow
graph LR
  Inner[内置编辑：Ctrl+S 保存] --> API[POST 保存 API]
  Ext[外部编辑器直接改文件] --> Watch[chokidar 目录监听]
  API --> File[写回源文件]
  File --> Watch
  Watch --> Reload[重载文档，新文件补写自动布局坐标]
  Reload --> Push[WS 推送最新 files]
  Push --> Swap[客户端原地替换，不刷新页面]
  Swap --> Fresh[画布与正文即时更新]
```

客户端收到推送后修剪暂存：内容一致的（保存生效）清除；磁盘上被删除的文件清除其暂存与删除标记——**新建文件的暂存除外**（写盘前磁盘上本就不存在，见 §2.5）。

除热更新闭环外，图编辑的暂存（内容、新建草稿、删除标记）还随操作**持久化到 localStorage**：刷新或重开页面后按磁盘基准校验恢复（已生效或已偏离的条目丢弃），有恢复时自动进入编辑模式提示保存或放弃——未保存的图修改不再因一次误刷新而丢失。

## 五、分层重排

```prodoc-flow
graph LR
  Btn[点 🧭 分层重排] --> Calc[computeLayeredLayout 忽略文件坐标]
  Calc --> Cover[全量覆盖坐标，平滑动画移动]
  Cover --> Back[点 ↩ 恢复坐标，还原文件坐标]
  Cover --> Drag[再拖拽单框：只写回该框，其余覆盖保留]
```

重排是纯视图层操作，不写文件；与拖拽编辑可叠加——保存时只写回被拖框的坐标，其余框的覆盖坐标保留在视图层。
