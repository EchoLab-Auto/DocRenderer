# ProDoc 规则定义

本文档是 ProDoc 文档框架的**权威规则定义**，描述文档如何被组织成「图」、如何被渲染。所有解析器、渲染器和文档作者的实现均以本文为准。

> 本文记录的是**当前已实现**的设计。规则与代码（`packages/prodoc-core/src/frame.ts`、`graph.ts`，`packages/prodoc-renderer/src/components/DocGraphViewer.vue`）严格对应。

## 一、核心模型：文档图

ProDoc 把一个文档目录（文档群）视为**一张图**，而非目录树：

- **每个 `.md` 文件 = 图上的一个框**（box）
- 框的全部属性（标识、标题、在画布上的位置与尺寸）由文件最前方的**框架参数区**声明
- 框间用 `link` 参数声明的有向连线表达导航关系，连线结构决定框的**层级深度**
- 相同 `group` 名的框被围入一个圆角矩形**分组区域**（见 §3.5）
- 正文的 **H2 标题**自动提取为**文档内分块**，在框内渲染为可跳转子块
- 文档群被整体渲染为一张可交互画布，点框即跳转到该文档的正文

```
文档群（目录）
   │
   ├── file1.md  ──参数区──→  图上框①
   ├── file2.md  ──参数区──→  图上框②
   └── ...
```

## 二、框架参数区

### 2.1 语法

每个 `.md` 文件的**最前方**（文件第 0 字节起）是由两个 `---` 行夹住的参数区：

```
---
id: getting-started
title: 快速开始
x: 40
y: 64
---

# 正文从这里开始……
```

- 第一行必须是单独的 `---`
- 之后是若干 `key: value` 参数行
- 以一行单独的 `---` 结束
- 结束行之后的所有内容即**正文**

### 2.2 剥离规则（渲染不可见）

参数区**仅供框架消费**，正文渲染时完全剥离：

- 解析阶段把文件拆为两部分：
  - **参数区**（两个 `---` 夹住的内容）→ 解析为框的参数
  - **正文**（第二个 `---` 之后）→ 唯一的渲染对象
- 读者在查看器中看到的一切（正文、目录、链接）均基于剥离后的正文；参数区不会出现在页面上

### 2.3 值类型

参数值按以下规则自动解析：

| 类型 | 示例 | 说明 |
|------|------|------|
| 整数 | `x: 40` | `^-?\d+$` |
| 浮点数 | `scale: 1.5` | `^-?\d*\.\d+$` |
| 布尔值 | `draft: true` | `true` / `false` |
| 内联列表 | `link: [guide, api]` | 方括号包裹、逗号分隔；成员继续按本表规则解析；可跨行书写（`[` 起、`]` 收，成员可各占一行） |
| 引号字符串 | `title: "快速开始"` | 双引号或单引号包裹，取内部内容 |
| 裸字符串 | `author: 张三` | 以上都不匹配时，原样作为字符串 |

### 2.4 容错

- 文件**不以 `---` 开头**：视为无参数区，整个文件按普通正文处理
- 文件以 `---` 开头但**找不到闭合的第二个 `---`**：视为无参数区，**整个文件（含开头的 `---`）按正文处理**——宁可显示原文，也不吞掉内容
- 参数区内**无法识别的行**：跳过，不中断解析

## 三、框的属性

### 3.1 框架保留字段

| 字段 | 类型 | 必填 | 缺省行为 |
|------|------|------|----------|
| `id` | `string` | 否 | 取文件相对路径去掉 `.md`，如 `guide/getting-started` |
| `title` | `string` | 否 | 取正文第一个 H1；再缺省取 `id` |
| `x` | `number` | 否 | 缺省时按连线层级分层自动布局（见 §四.3） |
| `y` | `number` | 否 | 同上 |
| `w` | `number` | 否 | `220`（`BOX_DEFAULT_W`） |
| `h` | `number` | 否 | `96`（`BOX_DEFAULT_H`） |
| `link` | `string[]` | 否 | 当前文档指向其他文档的连线，条目形如 `目标` 或 `目标 \| 标签` |
| `group` | `string` | 否 | 所属分组名；同组框在画布上被围入一个圆角矩形区域（见 §3.5） |

`id` 与 `title` 缺省回退链示意：

```
title:  参数区 title  →  正文第一个 H1  →  id
```

### 3.2 自定义字段

参数区中除上述保留字段外的任意字段，都会被解析并存入框的 `attrs` 对象，供框架或上层工具扩展使用。例如：

```yaml
---
id: api
title: "API 参考"
author: "张三"
tags: ["api", "reference"]
---
```

`author`、`tags` 不影响渲染，进入 `box.attrs`。

### 3.3 连线关系

`link` 直接声明当前文档指向其他文档的有向连线，方向为「当前文档 → 目标文档」：

```yaml
---
id: project
link: [guide, api]
---
```

条目可携带标签，`|` 之后的文字显示在连线中点；图编辑模式下**双击连线**可在中点输入框就地编辑（见 §5.3），无需手写：

```yaml
---
id: project
link: ["guide | 使用指南", api]
---
```

条目还可追加第三段指定**连接边**——`源边>目标边`，`t/r/b/l` 分别表示上/右/下/左，`_` 表示该端保持自动：

```yaml
---
id: project
link: ["guide | 使用指南 | b>l", "api | r>t", "note | t>_"]
---
```

缺省时按两框主导方向自动选边（见 §5.2）；图编辑模式下选中连线后**拖动端点手柄**即可调整（见 §5.3），无需手写。标签与连接边可按模式区分，互不占位：`user | r>l` 即「无标签、仅指定连接边」。

- 引用优先按文档 `id` 解析，也可写相对文档根的路径（`.md` 后缀可省略）
- 重复声明同一连线时自动去重
- 引用不存在的文档或连线自身时记录警告，不生成连线，也不中断渲染
- `link` 属于框架保留字段，不进入 `attrs`

### 3.4 文档内分块

正文的 **H2 标题**（`## 分块名`）会被自动提取为框的 `blocks`，在图画布上通过**悬停展开面板**展示：

- 仅当文档包含 **2 个及以上 H2** 时提取；代码围栏内的 `##` 不视为标题
- 分块标题取 H2 的纯文本（链接取文字、去除强调/代码标记）
- 悬停（或键盘聚焦）某个框时，从框底弹出分块面板；贴近画布底边的框向上弹出；**图编辑模式下不弹出**（避免遮挡拖拽与连线操作）
- 面板最多展示 **6 个条目**（`MAX_BLOCK_SLOTS`），超出折叠为一行 `+N 更多分块…`，点击打开文档
- 点击面板条目打开文档正文并**滚动到对应标题**（锚点 slug 与 ui-frame MarkdownRenderer 的标题 id 后缀一致）
- 分块不影响框的尺寸，框保持紧凑

### 3.5 文档分组

`group` 声明当前文档所属的分组，相同组名的框在画布上被围入一个**圆角矩形区域**（虚线描边 + 骑跨顶边的组名标签）：

```yaml
---
id: guide
group: 使用指南
---
```

- 一个文档最多属于一个组；声明多个（列表）时仅取第一个并记录警告；不支持嵌套
- 组标签即组名；分组仅影响画布视觉组织，不参与层级深度与分层布局计算
- `group` 属于框架保留字段，不进入 `attrs`

**区域几何**：缺省时区域 = 成员包围盒 + 内边距（左右/下 `24px` 即 `GROUP_PAD`，顶部 `34px` 即 `GROUP_LABEL_H` 留标签位），随成员移动自动重算。也可在任一成员的 group 条目上**显式声明区域几何**（沿用 prodoc-flow 的 `@` 坐标语法，扩展为四元组）：

```yaml
---
id: guide
group: "使用指南 @ 320, 120, 620, 220"
---
```

- 显式几何的区域**不随成员移动自动重算**（成员可被拖出区域）
- 多个成员声明几何且不一致时，取**按路径字典序首个声明者**（几何持有者，即 `DocGroup.holder`）并记录警告
- 图编辑模式下可**拖动组名标签整组移动**、**拖动区域右下角手柄调整长宽**，保存时写回（见 §5.3）
- 几何段不完整或不匹配时，整个值按组名处理（容错，不中断）

## 四、文档图构建

### 4.1 每文件一框

框架加载文档目录时，递归读取所有 `.md` 文件，每个文件经过 `parseFrameBlock` 解析后生成一个框，聚合成 `DocGraph`：

```
DocGraph {
  boxes: DocBox[]       // 全部框
  relations: DocRelation[] // link 声明的有向连线
  groups: DocGroup[]    // group 声明的分组区域
  warnings: string[] // 容错告警
}

DocBox {
  id, title,         // 标识与标题
  docPath,           // 对应文件相对路径
  depth,             // 层级深度（根框为 0，逐层 +1）
  blocks,            // 文档内分块（正文 H2 提取）
  x, y, w, h,        // 画布坐标与尺寸（px）
  attrs              // 自定义字段
}

DocGroup {
  name,              // 组名（区域标签文字）
  members,           // 成员框 id（按文件路径字典序）
  x, y, w, h,        // 区域位置与尺寸（px）
  explicit,          // 是否显式声明了几何
  holder             // 几何持有者的文档路径（画布调整的写回目标）
}
```

### 4.2 重复 id 的处理

同一 `id` 被多个文件声明时：

- 框按文件路径**字典序**依次加载
- **后者覆盖前者**
- 记录一条警告（`重复 id "xxx"：A.md 被 B.md 覆盖`），输出到控制台，**不中断渲染**

### 4.3 层级深度与分层自动布局

每个框根据 `link` 连线结构计算**层级深度**（`depth`）：

- **根框**（无入边）深度为 0，其余框深度 = 父框最大深度 + 1
- 环上的回边不参与深度贡献，任意图都可收敛

缺省 `x` / `y` 的框按深度**分层自动排布**：

- 深度相同的框同属一层，顶层为根框，逐层向下
- 层内按父框平均横坐标（重心）排序，减少连线交叉；无父框的框保持文件顺序排在右侧
- 每层从 `(48, 48)` 起按行排布，横向步距 `框宽 + 64`，层间（及层内换行）纵向间距 `72`
- 层过宽时按 `⌈√自动框数⌉` 列换行，行高取行内最高框（含分块自适应高度）
- 仅缺位置参数的框参与自动排布；显式给出坐标的框不受影响
- `view` 模式启动时会把自动计算出的缺失 `x` / `y` 写回对应 Markdown 的参数区，使布局固定下来
- 已有的有效数字坐标不会被覆盖；只缺一个坐标轴时仅补写缺失轴

### 4.4 画布尺寸

画布舞台（stage）尺寸 = 所有框与分组区域右下角的最大值 + 48px 边距，下限 `640×480`。

## 五、渲染

### 5.1 查看器（DocGraphViewer）

文档群被渲染为一张可交互画布（基于 `NeumorphismCanvas`）。完整交互流程图见 [交互设计](../interaction-design/interaction-design.md)：

| 交互 | 操作 |
|------|------|
| 平移 | 拖拽空白处（或 空格+拖拽） |
| 缩放 | Ctrl/Cmd + 滚轮（0.25×–3×） |
| 适配 | 工具栏一键缩放到完整可见 |
| 分层重排 | 头部「🧭 分层重排」按钮：忽略文件坐标全图重排，再点「↩ 恢复坐标」还原（仅当前视图，不写回文件） |
| 打开文档 | 单击框，或聚焦后按 Enter / Space |
| **图编辑模式** | 头部「🛠 编辑图」进入；以下八项仅在编辑模式下可用，修改先**暂存**为本地覆盖，「💾 保存」统一写回、「↩ 放弃更改」整批丢弃并退出，无暂存时「✓ 完成」退出 |
| **工具栏** | 编辑模式下画布底部居中悬浮（缩放控件上方）：🖱 选择（默认）/ 🔗 连线 / 📄 节点三工具；当前工具高亮，Esc 或点「🖱」切回选择，退出编辑状态复位 |
| **移动框** | 编辑模式（选择工具）下拖拽框（靠近其他框的边线/中线自动吸附对齐并显示参考线）；松开后暂存坐标修改，保存时**写回**该文件的参数区（`x`/`y`） |
| **移动整组** | 编辑模式下拖动组名标签：成员坐标整体平移（区域边线/中线与其他框、其他区域自动吸附对齐并显示参考线；显式几何组的区域同步平移）；松开后逐成员暂存，保存时写回各文件的 `x`/`y`（及几何持有者的 `group` 条目） |
| **调整组区域** | 编辑模式下拖动组区域右下角手柄调整长宽（右/下边缘与其他框、其他区域自动吸附；下限保证成员不外溢）；松开后区域转为显式几何，暂存到几何持有者的 `group` 条目（`名称 @ x, y, w, h`），保存时写回 |
| **创建连线** | 编辑模式下从框右边中点的连接点（选择工具）或连线工具下从任意框拖到目标框松手；暂存新条目，保存时追加到源文档的 `link` |
| **创建节点** | 编辑模式下选「📄 节点」工具，点画布空白在该位置创建新文档框（`untitled-N.md` 新文件暂存草稿，内容为 title/`x`/`y` 参数区 + 同名 H1）；保存时经保存 API 创建文件，放弃则消失；保存前不可打开正文 |
| **调整连接边** | 编辑模式下单击连线选中，**拖动端点手柄**到源框/目标框的任一条边松手，暂存条目第三段（如 `b>l`；只拖一端时另一端记为 `_` 保持自动），保存时写回 |
| **编辑连线标签** | 编辑模式下双击连线，中点弹出输入框（预填当前标签）；Enter/失焦确认、Esc 取消、清空移除标签段，暂存条目标签更新，保存时写回 |
| **删除连线** | 编辑模式下选中连线，点中点的「✕」或按 Delete / Backspace，暂存移除，保存时写回 |
| 编辑文档 | 悬停框点右上角 ✏️，或正文视图点「✏️ 编辑」；Ctrl/Cmd+S 保存 |
| 查看分块 | 悬停框展开分块面板，点击条目直达正文对应标题 |

### 5.2 框与连线的视觉

- 每个框按其 `x/y/w/h` 渲染为新拟态卡片，框面显示 `title`，保持紧凑
- **文档内分块**通过悬停展开的分块面板展示（见 §3.4），点击条目打开正文并滚动到对应标题
- **深度视觉分级**：根框（深度 0）加粗描边与标题；深度 2 描边变淡；深度 3 及以上变为虚线描边——层级深浅一眼可辨
- **分组区域**：`group` 同名的框被围入圆角矩形区域（虚线描边、微透明底色），组名标签骑跨区域顶边；区域位于连线与框之下且不响应指针；悬停框时无关联成员的组区域一并淡出
- `link` 声明的连线渲染为**贝塞尔曲线箭头**（声明方 → 目标）：默认按两框中心的主导方向自动选边（纵向流为底边中点 → 顶边中点，横向流为右边中点 → 左边中点，反向同理），也可用条目第三段显式指定连接边（§3.3）；控制点沿两端所连边的**外法线**布置，曲线在两端始终与边线法线相切；标签文字显示在连线中点，无标签时不显示文字
- **悬停高亮链路**：悬停某框时，其直接上下游框与相连连线高亮（连线转主色），无关元素淡出，便于在复杂图中追踪链路
- 框带 ↗ 图标表示可跳转；悬停上浮、聚焦高亮（无障碍可达）

### 5.3 画布编辑（图编辑模式）

头部「🛠 编辑图」切换图编辑模式：**关闭时画布是纯浏览**（单击框打开文档），**开启后**才开放以下编辑能力（单击框不再打开文档，避免拖拽误触；分块面板与框上的编辑入口在编辑模式下隐藏，防止带着未保存修改离开画布）。**修改不即时写文件**——所有编辑先**暂存为本地覆盖**，画布即时反映暂存结果：

- **拖拽移动框**：拖拽中连线实时跟随；与其他框的六条特征线（左/中/右、上/中/下）在阈值内自动**吸附对齐**并显示虚线参考线（阈值按缩放折算为屏幕约 8px）；松开后暂存新坐标（位移小于 3px 不触发拖拽），保存时通过 `writeFramePosition` 写回该文件参数区的 `x`/`y`
- **工具栏**：画布底部居中悬浮（缩放控件上方），🖱 选择（默认）/ 🔗 连线 / 📄 节点三工具；当前工具高亮，Esc 或点 🖱 切回选择，退出编辑状态时复位为选择
- **创建连线**：选择工具下从框右边中点的连接点拖出，或连线工具下从任意框按下拖出草稿曲线（激活期间框不可拖移），松手落在目标框上即暂存「源文档 `link` 末尾追加目标 `id`」；自连与重复连线自动忽略；保存时写回
- **创建节点**：节点工具下点画布空白，在该位置暂存新文件草稿 `untitled-N.md`（N 取磁盘与暂存中未占用的最小编号；内容为 `title`/`x`/`y` 参数区 + 同名 H1；点击点居中取整）；新框即时出现并可参与连线、整组移动与吸附；新建草稿不受热更新「磁盘不存在即清除」的修剪影响；保存时经保存 API 创建文件，「↩ 放弃更改」则消失；保存落盘前不可打开正文
- **调整连接边**：单击连线选中后，端点出现手柄；**拖动端点手柄**时按光标相对框心的方位实时预览目标边，松手暂存条目第三段更新（如 `guide | 指南 | b>l`）；只拖一端时另一端记为 `_`，保持自动选边；保存时写回
- **编辑连线标签**：双击连线，中点弹出内联输入框（预填当前标签并全选）；Enter 或失焦确认，Esc 取消；标签经 `buildLinkEntry` 重建条目——保留引用原文与连接边段，清空即移除标签段；未改动不产生暂存；输入期间 Delete / Backspace 作用于文本；保存时写回
- **删除连线**：选中连线后点中点的 ✕ 或按 Delete / Backspace，暂存从源文档 `link` 中移除匹配条目；保存时写回，`readFrameLinks`/`writeFrameLinks` 保证其余条目（含 `| 标签`、连接边原文）无损保留
- **移动整组**：拖动组名标签，成员坐标整体平移（逐框实时预览；区域边线/中线与其他框、其他组区域在阈值内自动**吸附对齐**并显示虚线参考线）；松开后逐成员暂存新坐标（`writeFramePosition`），显式几何组的几何持有者条目同步平移暂存（`writeFrameGroup`）；保存时逐文件写回
- **调整组区域**：拖动区域右下角手柄调整长宽（右/下边缘同样吸附对齐；下限 = 成员包围盒 + 内边距，保证成员不外溢）；松手后区域转为显式几何（`group: "名称 @ x, y, w, h"`），暂存到几何持有者文档；保存时写回

退出路径：「💾 保存」把全部暂存**逐文件批量写回**（携带冲突检测基准；全部成功后清空暂存、复位按钮，写盘成功的文件即时同步本地基准，服务端热更新随后推送最新文件重建画布；**写盘失败的文件保留暂存**并弹窗提示，可刷新页面后重试）并留在编辑模式；「↩ 放弃更改」整批丢弃（含拖框的位置覆盖）并退出编辑模式；无暂存修改时「✓ 完成」退出。改回原样（与磁盘内容一致）的修改自动撤销暂存，不计入待保存。

### 5.4 正文渲染与内置编辑

点击框后，查看器切换到文档正文视图：

- 用 `MarkdownRenderer` 渲染**剥离框架参数区后**的正文
- 正文内的**相对文档链接**（如 `[指南](./guide.md)`）可在查看器内继续跳转：链接经路径解析后定位到对应文件
- `prodoc-flow` 流程图块渲染为可交互画布；**节点可直接拖拽调整排版**，松手后坐标以 `@ x, y` 标注自动写回该代码块
- 正文第一个 `#`（H1）作为文档标题

浏览与编辑**一体化**：正文视图头部「✏️ 编辑」切换为 `MarkdownEditor`，编辑的是**原始完整文件内容**（含框架参数区——可直接修改 `x`/`y`/`link` 等参数）：

- 「💾 保存」或 Ctrl/Cmd+S 通过保存 API 写回源文件（仅脏内容可保存）
- 保存触发热更新回推：画布上的框位置、连线、分块随参数修改即时更新
- 「👁 预览」放弃未保存修改并回到渲染视图

### 5.5 视图切换与定位

- 顶部「🗺 返回图」按钮：从文档正文回到图画布
- 地址栏 hash 同步当前文档路径（如 `#guide/getting-started.md`），刷新或分享链接可直达该文档；无 hash 时默认显示图画布

## 六、完整示例

一个最小文档群：

```
my-docs/
├── index.md
├── guide.md
├── faq.md
└── note.md
```

`index.md`：

```markdown
---
id: home
title: 首页
x: 40
y: 40
w: 260
h: 120
link: ["guide | 指南"]
---

# 首页

这是文档群的入口。[前往指南](./guide.md)
```

`guide.md`（省略尺寸，用默认值；与常见问题同属「教程」组）：

```markdown
---
id: guide
title: 使用指南
x: 400
y: 40
group: 教程
---

# 使用指南

参数区不会被渲染，只看到这一段正文。
```

`faq.md`（同组框会被围入同一个分组区域）：

```markdown
---
id: faq
title: 常见问题
x: 400
y: 220
group: 教程
---

# 常见问题
```

`note.md`（无框架参数区，自动布局）：

```markdown
# 无参数区文档

这个文件没有参数区，会自动获得一个框，标题取自 H1。
```

渲染结果：画布上四个框——首页 `(40,40,260×120)`、使用指南 `(400,40,220×96)`、常见问题 `(400,220,220×96)`、无参数区文档（分层自动布局位置）；首页到使用指南有一条标注「指南」的箭头连线；使用指南与常见问题同属「教程」组，被一个圆角矩形区域围合（成员包围盒 + 内边距，顶边骑跨「教程」标签）；点击「首页」→ 看到「这是文档群的入口」，点击其中「前往指南」→ 跳到使用指南正文。
