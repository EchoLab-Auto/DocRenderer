# echo-prodoc

ProDoc 是一个 **Markdown 文档渲染与编辑框架**：把一个文档目录渲染为一张可交互的**文档图画布**——每个 `.md` 文件是图上的一个框，框间用 `link` 声明的箭头连线表达导航关系。

## 特性

- **文档图画布**：平移、缩放、一键适配；「🧭 分层重排」按连线层级一键重排全图
- **层级表达**：根框加粗、深层渐轻；悬停框高亮其上下游链路；悬停展开分块面板，点击直达正文对应标题
- **框架参数区**：文件最前方的 `---` 参数区声明框属性（id、标题、位置、连线），正文渲染时完全剥离
- **link 连线**：`link: ["目标 | 标签"]` 声明有向曲线箭头，连接框边缘中点，标签可选
- **浏览编辑一体化**：正文内相对链接继续跳转；「✏️ 编辑」就地修改原始文件，Ctrl/Cmd+S 保存后画布即时更新
