# 使用指南

## 安装

```bash
npm install -g @echolab-auto/echo-prodoc
```

## 快速开始

```bash
echo-prodoc view ./my-docs   # 渲染一个文档目录
```

浏览器自动打开后首先看到**图画布**：目录里每个 `.md` 文件一个框。点击任意框阅读正文，「🗺 返回图」回到画布。

## 写第一个文档群

最小文档群只需两个文件。

`index.md`：

```markdown
---
id: home
title: 首页
link: ["guide | 指南"]
---

# 首页

[前往指南](./guide.md)
```

`guide.md`：

```markdown
# 指南

没有参数区的文件也会自动获得一个框，标题取自正文第一个 H1。
```

- 缺省 `x`/`y` 的框按连线层级自动分层排布；`view` 模式会把自动计算的坐标**写回**参数区，使布局固定下来
- 参数区、连线、容错的完整规则见 [ProDoc 规则定义](../develop/prodoc-rule/prodoc.md)

## 查看器

- **画布交互**：拖拽平移、Ctrl/Cmd + 滚轮缩放、工具栏一键适配
- **🧭 分层重排**：忽略文件坐标按连线层级重排全图，「↩ 恢复坐标」还原
- **悬停探索**：悬停框高亮���上下游链路；含多个 H2 的文档会展开分块面板，点击条目直达正文对应标题
- **🛠 图编辑模式**：拖框、增删连线、拖动端点手柄调整连接边；修改先暂存（画布即时反映），「💾 保存」统一写回源文件，「↩ 放弃更改」整批丢弃
- **就地编辑**：打开文档后点「✏️ 编辑」修改原始内容（含框架参数区），Ctrl/Cmd+S 保存，画布即时更新
- **文档热更新**：磁盘上新增、修改、删除 `.md` 文件，页面原地更新，无需刷新
