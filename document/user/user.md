# 使用指南

## 安装

```bash
npm install -g @echolab-auto/echo-prodoc

# 升级到最新版
npm install -g @echolab-auto/echo-prodoc@latest
```

`echo-prodoc --version` 查看当前版本，`npm outdated -g` 列出可升级的全局包。

## 快速开始

```bash
echo-prodoc view ./my-docs   # 渲染一个文档目录
```

浏览器自动打开后首先看到**图画布**：目录里每个 `.md` 文件一个框。点击任意框阅读正文，「🗺 返回图」回到画布。

## 写第一个文档群

最小文档群只需两个文件。

`index.md`：

```markdown
---
id: home
title: 首页
link: ["guide | 指南"]
---

# 首页

[前往指南](./guide.md)
```

`guide.md`：

```markdown
# 指南

没有参数区的文件也会自动获得一个框，标题取自正文第一个 H1。
```

- 缺省 `x`/`y` 的框按连线层级自动分层排布；`view` 模式会把自动计算的坐标**写回**参数区，使布局固定下来
- 同组文档可在参数区声明 `group: 组名`，画布上被围入一个圆角矩形区域；也可显式指定区域几何（`group: "组名 @ x, y, w, h"`）
- 参数区、连线、分组、容错的完整规则见 [ProDoc 规则定义](../develop/prodoc-rule/prodoc.md)

## 查看器

- **画布交互**：拖拽平移、Ctrl/Cmd + 滚轮缩放、工具栏一键适配
- **🧭 分层重排**：忽略文件坐标按连线层级重排全图，「↩ 恢复坐标」还原
- **悬停探索**：悬停框高亮其上下游链路；含多个 H2 的文档会展开分块面板，点击条目直达正文对应标题
- **🛠 图编辑模式**：底部工具栏切换 🖱 选择 / 🔗 连线 / 📄 节点——拖框、增删连线（连接点或任意框拖出）、点空白创建新文档框、拖动端点手柄调整连接边、双击连线编辑标签；修改先暂存（画布即时反映），「💾 保存」统一写回源文件，「↩ 放弃更改」整批丢弃
- **分组编辑**：图编辑模式下拖动组名标签整组移动、拖动区域右下角手柄调整长宽，保存后写回各成员坐标与几何持有者的 `group` 条目
- **就地编辑**：打开文档后点「✏️ 编辑」修改原始内容（含框架参数区），Ctrl/Cmd+S 保存，画布即时更新
- **文档热更新**：磁盘上新增、修改、删除 `.md` 文件，页面原地更新，无需刷新
