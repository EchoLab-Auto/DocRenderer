# ProDoc 文档系统

欢迎使用 **ProDoc** —— 一个强大的文档渲染与编辑框架！

## 功能特性

- 📚 **Markdown 渲染** - 支持标准 Markdown 语法
- 🗺️ **文档图画布** - 每个文件一个框，`link` 连线表达导航，`group` 分组围合
- 🔄 **流程图支持** - 特殊语法定义交互式流程图
- ✏️ **在线编辑** - 直接在浏览器中编辑文档

## 快速开始

在图画布上点击任意框，浏览各章节文档。
